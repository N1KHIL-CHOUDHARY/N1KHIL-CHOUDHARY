### 🎵 Universal App Opener

Added **Spotify support** to Universal App Opener.

* Created a dedicated Spotify platform handler.
* Added dynamic URL detection for Spotify tracks, artists, albums, playlists, shows, episodes, and audiobooks.
* Implemented native deep links for **iOS** using the `spotify://` URI scheme.
* Implemented **Android** `intent://` deep links targeting the official Spotify package.
* Registered the new handler in the core platform system and updated platform types.
